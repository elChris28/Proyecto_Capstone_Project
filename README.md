# Asistente Inteligente de Inventario - Veterinaria

## Descripción
Sistema inteligente basado en NLP + Naive Bayes para gestión de inventario veterinario.

## Tecnologías
- Python
- Flask
- Scikit-Learn
- NLP (spaCy)
- MySQL

## Funcionalidades
- Consulta de stock
- Ubicación de productos
- Control de lotes y vencimientos
- Dashboard de métricas IA
- Chat inteligente

## Modelo IA
- TF-IDF + Multinomial Naive Bayes
- Clasificación de intenciones
- Métricas: Accuracy, Precision, Recall, F1

## Ejecución
```bash
pip install -r requirements.txt
python main.py
